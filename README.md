# Python Development Lab Assignments

A collection of my Python Development Lab (DEVL) assignments completed as part of my college coursework.

---

## 📚 Assignments

### Assignment 1 — Python Fundamentals & NumPy

Programs covering Python dictionaries, data structures, and basic matrix operations using NumPy.

- **[1A — Word Frequency](assignment-1/1a.py):** Count the frequency of each word in a given text using dictionaries.
- **[1B — Student Management System](assignment-1/1b.py):** Manage and analyze student data using lists, slicing, and dictionaries.
- **[1C — Matrix Operations](assignment-1/1c.py):** Perform matrix addition, subtraction, and multiplication using NumPy.

### Assignment 2 — Data Handling & Preprocessing

Programs focused on importing, exploring, and preprocessing datasets using Pandas.

- **[2A — Dataset Exploration](assignment-2/2a.py):** Import CSV, Excel, and JSON datasets and explore their structure and statistics using Pandas.
- **[2B — Data Preprocessing](assignment-2/2b.py):** Handle missing values, duplicates, outliers, categorical data, and feature scaling on a real-world dataset.

## ▶️ How to Run

Run on notebook environments like Google Colab and Jupyter Notebook. (Easiest Approach)

OR

Make sure Python 3 is installed.

Run any assignment using:

    python3 filename.py

For example:

    python3 1a.py

Install the required libraries using:

    pip3 install numpy pandas matplotlib seaborn
